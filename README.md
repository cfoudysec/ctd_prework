# CTD Python Intro Pre-Work

This repository contains my completed Coding the Dream Python Intro pre-work assignments. The exercises provided practice with basic Python programming and working with data and formulas in Google Sheets.

## Task 1: Python Script

The Python assignment is contained in `CTDPython.ipynb` and was completed using Google Colab.

The script simulates eligibility for an all-expenses-paid trip to Hawaii. It:

- Asks the user for their name and age using `input()`
- Stores the answers in variables
- Converts the age input to an integer
- Uses an f-string to display the user's name and age
- Uses an `if/else` conditional to determine whether the user is at least 18 years old
- Includes two documented example runs showing different outcomes

This exercise helped me practice variables, user input, data types, f-strings, conditional statements, and print statements.

## Task 2: Spreadsheet Practice

The spreadsheet assignment was completed in Google Sheets and exported as a CSV file.

The spreadsheet contains seasonal temperature and precipitation data for Raleigh, North Carolina; Seattle, Washington; and Phoenix, Arizona.

For this assignment, I used spreadsheet formulas to:

- Calculate the Year Average High temperature for each city using `AVERAGE`
- Determine the highest Year Average High using `MAX`
- Determine the lowest Year Average High using `MIN`
- Summarize what the data shows in a written description

The data showed that Phoenix had the highest yearly average high temperature, while Seattle had the lowest.

This exercise helped me practice using formulas, cell ranges, and basic data analysis in Google Sheets.
